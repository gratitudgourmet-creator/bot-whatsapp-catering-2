Documento Funcional — ERP
Gastronómico Integral para Eventos
1. Objetivo general
Crear una aplicación integral para administrar profesionalmente una empresa gastronómica
de eventos, desde el presupuesto inicial hasta el cierre final del evento.
El sistema deberá permitir controlar eventos, presupuestos, producción, compras, pedidos
internos, órdenes de compra, recepción de mercadería, stock, sobrantes, freezer/cámara,
bromatología, personal, convocatorias, horarios, sueldos, pagos, inventario interno, vajilla,
equipamiento, facturación, impuestos, reportes, alertas e inteligencia artificial.
2. Uso inicial
El sistema será desarrollado inicialmente para uso interno de la empresa, con el objetivo de
ordenar la operación, reducir pérdidas, mejorar controles, optimizar costos y profesionalizar
la gestión.
3. Uso futuro
Una vez probado internamente, el sistema podrá adaptarse como app comercial para otras
empresas gastronómicas, caterings, productoras y organizadores de eventos.
4. Plataformas deseadas
El sistema deberá funcionar en:
● aplicación Android;
● aplicación iPhone;
● panel web para PC;
● acceso por usuarios y permisos.
5. Principio central
Todo movimiento debe dejar registro.
Cada acción deberá guardar:
● usuario;
● fecha;

● hora;
● evento relacionado;
● módulo;
● observación;
● fotos si corresponde;
● estado;
● autorización si corresponde;
● historial.
6. Regla general de seguridad
Ningún usuario podrá ver costos, pagos, sueldos, gastos, márgenes ni movimientos de
dinero, salvo autorización expresa de Administración General.
