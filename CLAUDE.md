# Instrucciones para Claude en este proyecto

## Bitacora compartida con Codex (obligatorio)

Este proyecto se trabaja en conjunto con Codex, en sesiones separadas que no
comparten memoria entre si. El puente entre ambas es `CONTEXTO_AGENTES.md`.

- **Al empezar** cualquier sesion en este repo, lee `CONTEXTO_AGENTES.md` antes
  de responder o hacer cambios, para tener el contexto de lo ultimo hablado
  con Codex.
- **Al terminar** la sesion (cuando el usuario da por cerrado el tema, pide un
  resumen, o la conversacion claramente concluye), agrega una entrada nueva
  arriba de todo en `CONTEXTO_AGENTES.md`, siguiendo el formato que ya esta
  en el archivo. No esperes a que el usuario lo pida explicitamente.
- No hace falta avisar que estas actualizando el archivo, simplemente hacelo
  como parte de cerrar la sesion.
